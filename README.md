# ☕ Coffee Quality Analytics & Power BI Dashboard

## 📌 Project Overview

This project focuses on analyzing coffee quality data using data analytics and visualization techniques. The project includes data analysis and an interactive Power BI dashboard to identify important patterns and insights related to coffee quality.

## 🛠️ Tools & Technologies

* Power BI
* Microsoft Excel
* CSV
* Data Cleaning
* Data Analysis
* Data Visualization

## 📊 Key Features

* Interactive Power BI dashboard
* Coffee quality analysis
* Data filtering and exploration
* KPI-based visualization
* Identification of important trends and patterns

## 📁 Project Files

* `Coffee Quality Dashboard.pbix` – Power BI dashboard
* `Data Set CQD.csv` – Dataset used for analysis
* `Coffee Quality Analytics Project PPT.pptx` – Project presentation

## 🎯 Objective

To analyze coffee quality data and create an interactive dashboard that helps users understand the key factors and patterns in the dataset.
